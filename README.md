# Control de Posición Angular de un Aeropéndulo

## Descripción General
Este proyecto consiste en la automatización y estabilización de un aeropéndulo de un grado de libertad. 
El sistema funciona como un banco de pruebas físico para modelar dinámicas de vuelo y validar algoritmos de control en lazo cerrado (como un control PID). 
Su importancia radica en la capacidad de contrarrestar la fuerza de gravedad mediante el empuje generado por un motor y una hélice, 
logrando estabilizar el brazo articulado en una posición angular deseada a través de un microcontrolador STM32F407G-DISC1.
